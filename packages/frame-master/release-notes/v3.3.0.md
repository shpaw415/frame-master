## 3.3.0 Release (draft)

Ship this note when bumping `package.json` to `3.3.0`.

### Highlights

- **Plugin test suite:** new top-level `test-suite/` published as `frame-master/testing` (and `frame-master/test-suite`). Plugin authors can integration-test HTTP, the request pipeline, and the unified **build** pipeline with `createPluginTestEnv`.
- **OIDC npm release:** GitHub Actions workflow `release.yml` publishes to npm via Trusted Publisher when a new version appears in `package.json` on `main` (no long-lived npm token).
- **Plugin create:** scaffolds a sample `plugin.test.ts` and documents testing in the plugin README template.
