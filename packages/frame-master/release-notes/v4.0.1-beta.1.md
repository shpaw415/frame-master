## 4.0.1-beta.1

Plugin tests that construct `BuildUnifier()` no longer leak that pipeline from the runtime preload into the test run.

- `loadRuntimePluginFromPlugins` drops pipelines created while building the preload plugin list.
- `createPluginTestEnv` attaches and initializes those pipelines before `serverStart`.
- `dispose()` clears the pipeline registry and the plugin-loader singleton so the next test can register the same names.
