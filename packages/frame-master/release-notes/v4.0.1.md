## 4.0.1

Stable release of the plugin-test pipeline fixes.

- Preload no longer leaves a `BuildUnifier` pipeline registered for the test run.
- `createPluginTestEnv` attaches and initializes pipelines before `serverStart`.
- `dispose()` clears the pipeline registry and the plugin-loader singleton.
- `env.build()` runs every `BuildUnifier` pipeline, matching `frame-master build`.
- Debug build starts the file watcher before the first build so CI rebuilds are not missed.
