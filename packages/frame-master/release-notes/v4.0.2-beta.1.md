## 4.0.2-beta.1

`build.finally("html")` runs on real HTML entrypoints when the virtual-module plugin is in the same build.

- A namespace-restricted `onLoad` no longer counts as covering the file namespace, so `frame-master-virtual-modules` (`filter: /.*/`) does not suppress finally-only HTML handling.
- Finally-only seeding reads `build.config.files` before disk. If neither exists, the handler returns `undefined` instead of throwing `ENOENT` and dropping every HTML output.
- Disk-only `finally("html")` behavior is unchanged.
